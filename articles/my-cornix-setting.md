Keychronとギズモード・ジャパンが共同開発した[Keychron Orca echo](https://costory.jp/cf-published-sku-groups/1955012598)のクラウドファンディングが5億円を超えるなど、分割キーボードが最近盛り上がってきていますね！

私は、昨今の盛り上がりの火付け役となったと思われるCornixを使っているのですが、いろいろと試行錯誤しながら設定を変えてきました。変更する度に、「今回は完璧だな〜」と思うんですが、その後に更に良い設定を思いついたり、変更してみたら不都合が生じたりしたため、何度も何度も変更してきました。
今回こそ完璧にできたと思うので、ここにその究極の設定をまとめておこうと思います。もうこれ以上の設定はないはずなので、ここから変更することはないでしょう。たぶん。

## Cornixとは

設定紹介の前に、Cornixについて簡単に説明しておきます。
https://jezailfunder.jp/products/cornix-lp-keyboard
https://cornixhub.com/beginner-guide

> Cornixは、カスタマイズ可能な分割型キーボードです。Vialソフトウェアを使用して、キーマップやマクロを自由にカスタマイズできます。
> - 分割型エルゴノミックデザインで手首への負担を軽減
> - Vialによる直感的なキーマップ設定
> - レイヤー機能で複数のキー配置を切り替え可能
> - マクロ、タップダンス、コンボなどの高度な機能

普通のキーボードと比べてキー数が少ないため、レイヤー、タップダンス（TD）、マクロ、コンボといった機能を使う必要があります。詳細に関しては、[Vial 使い方](https://cornixhub.com/vial-guide)を参照してください。

## 設計思想

トラックパッドやマウスなどのポインティングデバイスを使わずに、ホームポジション付近のキーでカーソル操作やアプリの切り替えなども含めた全ての操作ができるようにしています。
実際には [Nape Pro](https://superkopek.jp/pages/napepro-news) というトラックボールを使用しているので、ポインティングデバイスを使ってはいます。
![](/images/cornix/cornix_napepro.png)

チャンスがあれば[moNa2](https://booth.pm/ja/items/6376654)も手に入れたい思っているので、どちらでも同様に操作できるように、moNa2に合わせて左右の両端の列は使わない縛りを入れています。
そのおかげで運指が最小限で済むようになり、快適にタイピングできるようになりました。

## Layer 0

![](/images/cornix/layer0.png)

デフォルトのレイヤーで、文字入力や、他のレイヤーへの切り替え、bluetooth機器の切り替えを行います。

- 左手側のホームポジションには[home row mods](https://precondition.github.io/home-row-mods)として、長押し中に修飾キーが発動するようになっていて、小指側から順にCtrl、Opt、Cmd、Shiftにしています
- home row modsは両手に設定するものなので右手側にも設定していたこともあったのですが、誤爆が多かったのでやめて、その代わりにVim以外の環境でもVimのカーソル操作ができるように、h, j, k, lのキーにTDの長押しで矢印キー（←↓↑→）を設定
- ホームポジションに修飾キーと矢印キーを割り当てていることによって、様々な操作がホームポジション付近のキーだけでできるようになっています
  - `Cmd + ←↓↑→`で、カーソルを上下左右の両端に一瞬で移動
  - ブラウザやSlackでは`Cmd + ←→`で「戻る」と「進む」、ブラウザでは`Cmd + Opt ←→`でタブ移動
  - RaycastのNext Displayは、アクティブなアプリを別のディスプレイに飛ばすことができる機能で、そのHotkeyに`Ctrl + Shift + →`を割り当てています
  - 後述の通り、私の設定ではアプリを一瞬で切り替えられるようになっているので、Mission Controlや仮想デスクトップの移動は使いませんが、Ctrlとの組み合わせで発動できます
- Escは、Vim定番のjのダブルタップで発動するようにしていて、発動した際はVimのノーマルモードでの操作のために必ず英字入力になるようにマクロを設定してあります
- Tabは、aとsのコンボで発動
- 英字入力はfとEnterのコンボ、日本語入力はTD(1)とSpaceのコンボで切り替え
- 左手の親指の3つのキーには、左から順にBS、Enter、TD(21)でLayer 1への切り替えを、右手の親指の3つのボタンには、右から順にDelete、Space、TD(22)でLayer 2への切り替えを設定
  - キー配置とカーソル移動の位置関係を合わせるようにしていて、BSは左側に移動するから左側に、SpaceとDeleteは右側に移動するから右側に配置することによって直感的に操作できるようにしています
  - moNa2では、Cornixの右手親指側の右端のキーの位置にトラックボールがあることによりキーが1つ少ないため、最悪無くても困らず、`Ctrl + d`で代用できるDeleteをその位置に割り当てています
  - 前述の通りhome row modsを左手側にしか設定していないので、よく使うCmdやShiftと、左手側のキーと組み合わせて押すことが難しいキーがあるため、Enter長押し中はCmd、Space長押し中はShiftが発動するように設定
  - レイヤー切り替えのTDには、タップ時は次のキーが入力されるまでの一時的な切り替え（いわゆるOne Shot Key）、長押し中は押している間だけの一時的な切り替え、ダブルタップで完全に切り替えるように設定
- TD(4)からTD(8)は、ダブルタップでCmdとのショートカットが発動するようにしていて、例えば、TD(6)の位置はcのキーなので、ダブルタップでコピーできるようにしています
  - TD(4)は`Cmd + z` の取り消し（いわゆるundo）
  - TD(5)は`Cmd + x` の切り取り
  - TD(6)は`Cmd + c` のコピー
  - TD(7)は`Cmd + v` の貼り付け
  - TD(8)に関しては、`Cmd + b`は使わないため、`Cmd + Shift + z` の取り消しを戻す（いわゆるredo）を設定
- RaycastのHotkeyでよく使うアプリなどを一瞬で呼び出せるようにしてあり、例えば、`Hyper（Ctrl、Opt、Cmd、Shiftの同時押し） + s`にはSlackを割り当てているのですが、両手親指内側のTD(21)とTD(22)のコンボでHyperのOne Shot Keyを発動するようになっています
  - ターミナルは`Hyper + t`(今はWezTermとHerdrを組み合わせて使っていますが、今後ツールを変更したとしてもキーを変更しなくてすむようにtに設定)
  - ブラウザは`Hyper + b`（今はBraveを使っていてたまたまキーが合致している）
  - Slackは`Hyper + s`
  - VS Codeは`Hyper + v`
  - Figmaは`Hyper + f`
  - Obsidianは`Hyper + o`
  - 上記以外の開いているアプリを呼び出す際は、RaycastのSwitch Windowsを使用`Hyper + w`
  - RaycastのQuicklinksのSearch Googleは`Hyper + g`
  - RaycastのGitHubの拡張機能で検索
    - Search Repositoriesは`Hyper + r`
    - My Pull Requestsは`Hyper + p`
    - My issuesは`Hyper + i`
  - RaycastのClipboard Historyは`Hyper + c`
  - RaycastのWindow Managementでアクティブなアプリのサイズを変更できるので、Vimのキーバインドと組み合わせて`Hyper + hjkl`で画面の上下左右の半分のサイズに変更、`Hyper + m`で最大化できるように設定
- 左手側の下部にはNape Proを置いてあるので、それと組み合わせてマウスクリックやブラウザ操作を左手側だけでできるように下記の通り設定
  - TD(4)とTD(5)のコンボで左クリック
  - TD(5)とTD(6)のコンボで中央クリック
  - TD(6)とTD(7)のコンボで右クリック
  - TD(5)からTD(8)の長押しにはマウススクロールを割り当てており、Vimの右手ホームポジションのカーソル操作を上下だけ入れ替えたもの(←↑↓→)を割り当てるというクセ強めな設定にしています（Macだとナチュラルスクロールの関係で左右反転させる必要があり、左側のTD(5)にMouse Scroll Rightを、右側のTD(8)にMouse Scroll Leftを設定）
  - TD(4)の長押しにはOptを割り当てていて、[BetterTouchTool](https://folivora.ai/)というアプリを使って、上下のマウススクロールと組み合わせることで、トラックパッドと同じ挙動のズームイン・ズームアウトできるようにしています
  - Hyperとの組み合わせでアプリを一瞬で切り替えられるため、基本的にMission Controlは使わないのですが、左手だけで操作している時に切り替えられるようにeとrのコンボで発動するようにしています
  - タブやウィンドウを閉じるために、qとwのコンボに`Cmd + w`を設定
  - 最上部と最下部にスクロールするために、wとeとrのコンボでHome、qとwのeコンボでEndが発動
  - a, s, d, fのコンボに、前述のRaycastのNext Displayを割り当て
  - 左下の3つのキーの両端に左右の矢印キーを割り当てていて、真ん中のCmd(LGui)との組み合わせで「戻る」と「進む」ができるようになっており、更に、前述の通りTD(4)の長押しはOptなので、左手薬指でTD(4)とLGuiの縦に並んだ2つのキーを押しながら左右の矢印キーを押すというテクニカルな押し方でタブ移動ができるようになっています
- くるくる回すことができるロータリーエンコーダーは、右手側のクリック以外はデフォルトです
  - 左手側の回転は音量変更、クリック時はミュート
  - 右手側の回転の上下のマウススクロールとOptとの組み合わせで、前述のズームイン・ズームアウトができるようになっており、クリック時はデスクトップ表示に変更しています

## Layer 1

![](/images/cornix/layer1.png)

数字と記号のレイヤーです。

- 親指キーの▽とはなんぞや？という感じだと思いますが、これは前のLayer 0のキーを引き継いでそのまま使う特殊なキーです
- 10個の数字を真ん中の行に横一列に並べることによって、ホームポジションで5と6以外の数字を指を動かすことなく入力できるようになっています
- Layer 1は、左右にhome row modsを設定しています
- 両手人差し指のShiftか、右手親指中央のShiftと数字キーとの組み合わせで、記号入力もできます
- 数字に関する記号として、左手側の下部に四則演算の記号、上部に小数点を配置
- Layer 0にある記号と上記の記号以外のものを、右手側に配置
- TD(20)のタップにEsc、ダブルタップにTO(0)を割り当てており、TO(0)は、Layer 1に完全に切り替えた際にLayer 0に戻るためのキーです
- このレイヤーのロータリエンコーダーは使わないので、デフォルトのままです

## Layer 2

![](/images/cornix/layer2.png)

右手側でカーソルや画面操作をするためのレイヤーです。
BetterTouchToolの設定で、スクロール時の動きをトラックパッドでの操作のように滑らかになるようにしています。
前述のとおり、Layer 0の左手側にはNape Proを置いてあるので、左右どちらでもカーソル操作ができるようになっています。

- 右手側は、カーソル操作やスクロールのためのキーを設定
  - ホームポジションの行のカーソル操作は、Vimと同様に設定（←↓↑→）
  - 真ん中の行の小指側のMouse Accel 2は、押している間はカーソルのスピードが速くなります
  - EscとLayer 0に戻るキーを割り当てているTD(20)は、Layer 1と同じ位置に配置
  - ホームポジションの上の行には、入力欄でちょっとした操作ができるように、Enter、Space、BS、Deleteを配置
  - 両手の親指のキーにはマウスクリックを配置
  - Layer 0の左手側に設定してあるマウスクリックのコンボ、スクロール、ズームイン・ズームアウトやその他全ての操作は、Layer 0を左右反転させた位置に設定
  - ウィンドウを閉じる`Cmd + w`は、Layer 2ではBSとDeleteのコンボで設定していますが、Layer 0では両手親指の両端の位置に配置してあったので、偶然の結果なのですが、これが結構便利に使えて気に入っています
- 左手側はLayer 0の修飾キーやCmdキーとの組み合わせをそのまま利用するために▽を設定
- ロータリーエンコーダーは全て変更しています
  - 左手側の回転は`Cmd + +-`で画面の拡大・縮小（表現がなかなか難しいのですが、ここの拡大・縮小は、前述のズームイン・ズームアウトとは挙動が異なります）を割り当てていて、クリック時は元のサイズに戻るようにしています
  - 右手側の回転はディスプレイの照度の変更、クリック時はデスクトップ表示にしています

## 詰まったところ

- 修飾キーをマクロで使う際の注意点として、Down（ボタン押し下げ）した後にUp（ボタン押し上げ）をしないと修飾キーが押されたままの状態になってしまうのですが、単純にUpだけだと、DownとUpが同時に押されたと認識されるためか、修飾キーが解除されないようなので、Upする前にDelayで10ミリ秒遅らせる必要がありました
- TDやQuantumなどの特殊なキーをコンボで設定する場合、タップ時のキー（下記の画像の例ではaとs）ではなく、その設定したキー自体を設定する必要があります

## おわりに
タイピングやカーソル操作は日々数え切れないほど何回も行うものです。
キーマップを変更できるキーボードを使うまでは、修飾キーや、Enter、BSの位置にそこまで不便を感じていませんでしたが、今となっては、通常のキーマップだと、「修飾キー押しにくい！」、「EnterとかBSって頻繁に押すキーなのに、なんでこんなに遠い位置に配置してあるんだ？」と感じるようになりました。

この記事で紹介した設定は、他のツールや、Vim、home row modsを組み合わせてごちゃ混ぜにしているため、クセ強に思われるでしょうし、実際かなりクセは強いのですが、使っている当人にとっては、日々作業する中で何回もカスタマイズして改良を重ねてきたものなので、本当に操作しやすく、毎日快適に作業できるようになっています。

人とPCを繋ぐインターフェースは、キーボードやマウスといった入力デバイスですが、これらの追加・変更や、設定のカスタマイズによって操作性が向上すると、思考や思想、作業環境が劇的に変わるんだなと実感しています。

キーマップの最適化によってショートカットによる操作が快適にできるようになると、なるべくマウスなどのポインティングデバイスを使わず、キーボードから手を離さずに作業したくなってきます。

アプリを一瞬で切り替えることができるようになると、複数のモニターは不要になるというか、むしろ視線やカーソルを移動させるのが煩わしくなるので、今はモニター1枚で作業するようになっていて、仮想デスクトップさえも使っていません。PC本体の画面ではデスクトップを表示していて、ファイル置き場としてしか使っていないので、外出時にモニターがない環境であっても最悪PCの画面だけで何とかなりそうだと思っています。

ブラウザに関しても、以前はタブをたくさん開きっぱなしにしていたのですが、VimiumやRaycastのGitHub拡張機能との組み合わせによって、タブ、ブックマーク、履歴や、Pull Request、Issueを検索して一瞬で開けるようになったので、用が済んだらすぐ閉じるようになり、タブを探してクリックすることがほぼなくなりました。

この境地に至るまでには、Vimの習得や、Mac・各種アプリのショートカットを覚えるのも含めてとても長い道のりであったので、安易におすすめできませんが、少しでもキーボードに興味を持ってもらい、まずは、1つのキーからでも良いので、[Karabiner-Elements](https://karabiner-elements.pqrs.org/)などを使用してキーマップを変更してみようかなと思ってもらえたら嬉しいです！

少しずつ自分好みにカスタマイズしていければ、操作性が向上し、どんどん快適になっていくはずです。是非あなただけの最強の設定を探してみてください。
