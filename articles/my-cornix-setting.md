## Cornixとは

設定紹介の前に、Cornixについて簡単に説明しておきます。
https://jezailfunder.jp/products/cornix-lp-keyboard
https://cornixhub.com/beginner-guide

> Cornixは、カスタマイズ可能な分割型キーボードです。Vialソフトウェアを使用して、キーマップやマクロを自由にカスタマイズできます。
> - 分割型エルゴノミックデザインで手首への負担を軽減
> - Vialによる直感的なキーマップ設定
> - レイヤー機能で複数のキー配置を切り替え可能
> - マクロ、タップダンス、コンボなどの高度な機能

普通のキーボードと比べてキー数が少ないため、レイヤー、タップダンス（TD）、マクロ、コンボといった機能を使う必要があります。詳細に関しては、[Vial 使い方](https://cornixhub.com/vial-guide)を参照してください。

## 設計思想

トラックパッドやマウスなどのポインティングデバイスを使わずに、ホームポジション付近のキーだけでカーソルやポインタ操作、アプリの切り替えなども含めた全ての操作をできるようにしています。
とはいえ、実際には [Nape Pro](https://superkopek.jp/pages/napepro-news) というトラックボールを併用しているので、ポインティングデバイスを使ってはいます。
![](/images/cornix/cornix_napepro.png)

チャンスがあれば[moNa2](https://booth.pm/ja/items/6376654)も手に入れたいと思っているので、どちらでも同じように操作できるように、moNa2に合わせて左右両端の列は使わないという縛りを入れていたのですが、そのおかげで運指が最小限で済むようになってタイピングが更に快適になるという嬉しい副作用がありました。

## Layer 0：文字入力とアプリ呼び出しのレイヤー

![](/images/cornix/layer0.png)

デフォルトのレイヤーで、文字入力やアプリ呼び出し・他のレイヤーへの切り替え、Bluetooth機器の切り替えを行います。

### home row modsと矢印キー

- 左手側のホームポジションには[home row mods](https://precondition.github.io/home-row-mods)として、長押し中に修飾キーが発動するようになっており、小指側から順にCtrl、Opt、Cmd、Shiftを割り当て
- home row modsは、本来は両手に設定するものなので、右手側にも設定していた時期もあったのですが、誤爆が多かったのでやめて、代わりにh, j, k, lのキーにTDの長押しで矢印キー（←↓↑→）を割り当て、Vim以外の環境でもVimと同じ操作でカーソルを動かせるようにしています
- ホームポジションに修飾キーと矢印キーを割り当てたことによって、様々な操作がホームポジション付近のキーだけで完結するようになりました
  - `Cmd + ←↓↑→`で、カーソルを上下左右の両端に一瞬で移動
  - ブラウザやSlackでは`Cmd + ←→`で「戻る」と「進む」、ブラウザでは`Cmd + Opt ←→`でタブ移動
  - [Raycast](https://www.raycast.com/)のNext Displayはアクティブなアプリを別のディスプレイに飛ばす機能で、そのHotkeyに`Ctrl + Shift + →`を割り当てています
  - 後述の通りアプリを一瞬で切り替えられるようにしてあるため、Mission Controlや仮想デスクトップの移動は使いませんが、Ctrlとの組み合わせで発動できます
### コンボとダブルタップで補う基本キー

- Escは、Vim定番のjのダブルタップで発動するようにTD(1)に設定しており、さらに必ず英字入力に切り替わるようマクロを組んであるので、そのままVimのノーマルモードでの操作に移れます
- Tabは、aとsのコンボで発動（home row modsのCtrl、Optとバッティングしますが、現状では使っているショートカットがないため問題なし）
- 英字入力はfとEnterのコンボ、日本語入力はTD(1)とSpaceのコンボで切り替え

### 親指キー

左手の親指の3つのキーには、左から順にBS、Enter、Layer 1へ切り替えるTD(21)を、右手の親指の3つのキーには、右から順にDelete、Space、Layer 2へ切り替えるTD(22)を設定しています。

- キー配置とカーソルの移動方向を合わせるようにしていて、BSはカーソルが左に動くので左側に、SpaceとDeleteは右に動くので右側に配置することによって直感的に操作できるようにしています
- moNa2では、Cornixの右手親指側の右端キーの位置にトラックボールがあることによりキーが1つ少ないため、最悪無くても困らず、`Ctrl + d`で代用できるDeleteをその位置に割り当てました
- home row modsを左手側にしか設定していないので、よく使うCmdやShiftを左手側のキーと組み合わせて押しにくい場面があるため、Enter長押し中はCmd、Space長押し中はShiftが発動するようにしました
- レイヤー切り替えのTDには、タップ時は次のキーが入力されるまでの一時的な切り替え（いわゆるOne Shot Key）、長押し中は押している間だけの一時的な切り替え、ダブルタップで完全に切り替えるように設定

### ダブルタップで発動するCmdショートカット

TD(4)からTD(8)は、ダブルタップでCmdとのショートカットが発動するようにしていて、例えばTD(6)の位置はcのキーなので、ダブルタップでコピーできます。

- TD(4)は`Cmd + z` の取り消し（いわゆるundo）
- TD(5)は`Cmd + x` の切り取り
- TD(6)は`Cmd + c` のコピー
- TD(7)は`Cmd + v` の貼り付け
- TD(8)は`Cmd + b`を使わないため、`Cmd + Shift + z` の取り消しを戻す（いわゆるredo）を設定

### Raycastによるアプリの呼び出しとウィンドウ操作

RaycastのHotkeyで、よく使うアプリなどを一瞬で呼び出せるようにしてあり、修飾キーには`Hyper`（Ctrl、Opt、Cmd、Shiftの同時押し）を使い、これを両手親指内側のTD(21)とTD(22)のコンボでOne Shot Keyとして発動するようにしています。

- ターミナルは`Hyper + t`（今はWezTermとHerdrを組み合わせて使っていますが、今後ツールを変更してもキーを変えずに済むようにしています）
- ブラウザは`Hyper + b`（今はBraveを使っていて、たまたまキーが合致している）
- Slackは`Hyper + s`
- VS Codeは`Hyper + v`
- Figmaは`Hyper + f`
- Obsidianは`Hyper + o`
- 上記以外の開いているアプリを呼び出す際は、RaycastのSwitch Windowsを使用`Hyper + w`
- RaycastのQuicklinksのSearch Googleは`Hyper + g`
- RaycastのGitHubの拡張機能で検索
  - Search Repositoriesは`Hyper + r`
  - My Pull Requestsは`Hyper + p`
  - My issuesは`Hyper + i`
- RaycastのClipboard Historyは`Hyper + c`
- RaycastのWindow Managementでアクティブなアプリのサイズを変更できるので、Vimのキーバインドに合わせて、`Hyper + hjkl`で画面の上下左右半分のサイズに変更、`Hyper + m`で最大化するように設定

### 左手だけで完結させるマウス操作

左手側の下部にはNape Proを置いてあるので、それと組み合わせて、マウスクリックやブラウザ操作を左手側だけでできるように下記の通り設定しています。

- TD(4)とTD(5)のコンボで左クリック
- TD(5)とTD(6)のコンボで中央クリック
- TD(6)とTD(7)のコンボで右クリック
- TD(5)からTD(8)の長押しにはマウススクロールを割り当てており、並びは、Vimの右手ホームポジションのカーソル操作から上下だけを入れ替えたもの（←↑↓→）という、クセ強めの設定です（Macだとナチュラルスクロールの関係で左右を反転させる必要があるため、左側のTD(5)にMouse Scroll Right、右側のTD(8)にMouse Scroll Leftを設定）
- TD(4)の長押しにはOptを割り当てていて、[BetterTouchTool](https://folivora.ai/)というアプリを使い、上下のマウススクロールと組み合わせることで、トラックパッドと同じ挙動でズームイン・ズームアウトできます
- Hyperとの組み合わせでアプリを一瞬で切り替えられるため、Mission Controlは基本的に使わないのですが、左手だけで操作している時に切り替えられるように、eとrのコンボで発動するようにしています
- タブやウィンドウを閉じるために、qとwのコンボに`Cmd + w`を設定
- 最上部と最下部にスクロールするために、wとeとrのコンボでHome、qとwとeのコンボでEndが発動
- a, s, d, fのコンボに、前述のRaycastのNext Displayを割り当て
- 左下の3つのキーは、両端に左右の矢印キー、真ん中にCmd(LGui)を割り当てていて、組み合わせれば「戻る」と「進む」ができるようになっており、さらに、前述の通りTD(4)の長押しはOptなので、左手薬指でTD(4)とLGuiの縦に並んだ2つのキーをまとめて押しながら左右の矢印キーを押すという、かなりテクニカルな押し方でタブ移動もできます

### ロータリーエンコーダー

くるくる回すことができるロータリーエンコーダーは、右手側のクリック以外はデフォルトです。

- 左手側の回転は音量変更、クリック時はミュート
- 右手側の回転は上下のマウススクロールなので、Optと組み合わせれば前述のズームイン・ズームアウトができるようになっており、クリック時はデスクトップ表示に変更しています

## Layer 1：最小限の運指で入力する数字と記号のレイヤー

![](/images/cornix/layer1.png)

数字と記号のレイヤーです。
親指キーの▽とはなんぞや、という感じだと思いますが、これは下のレイヤー（ここではLayer 0）のキーをそのまま引き継いで使う特殊なキーです。

### 数字と記号の配置

- 10個の数字を真ん中の行に横一列に並べたことによって、5と6以外の数字はホームポジションから指を動かすことなく入力できます
- 両手人差し指のShiftか、右手親指中央のShiftと数字キーとの組み合わせで、記号入力もできます
- 数字に関する記号として、左手側の下部に四則演算の記号、上部に小数点を配置
- Layer 0にある記号と上記の記号以外のものは、右手側に配置

### そのほかのキー

- Layer 1では、左右両方にhome row modsを設定しています
- TD(20)は、タップにEsc、ダブルタップにTO(0)を割り当てていて、TO(0)は、Layer 1に完全に切り替えた状態からLayer 0に戻るためのものです
- このレイヤーのロータリーエンコーダーは使わないので、デフォルトのままです

## Layer 2：右手でポインタと画面を操作するレイヤー

![](/images/cornix/layer2.png)

右手側でポインタや画面の操作をするためのレイヤーです。
スクロール時の動きは、BetterTouchToolの設定でトラックパッドの操作のように滑らかにしています。
前述の通り左手側の下部にはNape Proを置いてあるので、これで左右どちらでもポインタ操作ができるようになっています。

### 右手側：ポインタ操作とクリック

- ホームポジションの行のポインタ操作は、Vimのカーソル操作と同じ配置に設定（←↓↑→）
- 真ん中の行の小指側のMouse Accel 2は、押している間はポインタのスピードが速くなります
- EscとLayer 0に戻るキーを割り当てているTD(20)は、Layer 1と同じ位置に配置
- ホームポジションの上の行には、入力欄でちょっとした操作ができるように、Enter、Space、BS、Deleteを配置
- 両手の親指のキーにはマウスクリックを配置
- Layer 0の左手側に設定してあるマウスクリックのコンボ、スクロール、ズームイン・ズームアウトやその他全ての操作は、Layer 0を左右反転させた位置に設定
- ウィンドウを閉じる`Cmd + w`は、Layer 2ではBSとDeleteのコンボに設定していますが、Layer 0ではBSとDeleteは両手親指の両端に配置してあるので、偶然の結果なのですが、これが押しやすくてかなり便利に使えているので気に入っています

### 左手側とロータリーエンコーダー
- 左手側は、Layer 0の修飾キーやCmdキーとの組み合わせをそのまま利用するために▽を設定しています
- ロータリーエンコーダーは全て変更しています。
  - 左手側の回転には`Cmd + +-`による画面の拡大・縮小を割り当て、クリック時は元のサイズに戻るようにしています（表現がなかなか難しいのですが、ここでの拡大・縮小は前述のズームイン・ズームアウトとは挙動が異なります）
  - 右手側の回転はディスプレイの照度の変更、クリック時はデスクトップ表示にしています

## 詰まったところ

- 修飾キーをマクロで使う場合、Down（ボタン押し下げ）した後にUp（ボタン押し上げ）をしないと、修飾キーが押されたままの状態になってしまうのですが、DownのすぐあとにUpを置くだけだと、DownとUpが同時に押されたと認識されるためか修飾キーが解除されないようで、Upの前にDelayで10ミリ秒遅らせる必要がありました
- TDやQuantumなどの特殊なキーをコンボで設定する場合、タップ時のキー（下記の画像の例ではaとs）ではなく、その設定したキー自体を指定する必要があります

## おわりに
タイピングやカーソル・ポインタの操作は、日々数え切れないほど何回も行うものです。
キーマップを変更できるキーボードを使うまでは、修飾キーやEnter、BSの位置にそこまで不便を感じていませんでした。ところが今では、通常のキーマップだと「修飾キー押しにくい！」「EnterとかBSって頻繁に押すキーなのに、なんでこんなに遠い位置に配置してあるんだ？」と感じるようになりました。

この記事で紹介した設定は、Vimやhome row mods、他のツールの機能をごちゃ混ぜにして取り入れているため、クセ強に思われるでしょうし、実際かなりクセは強いですが、使っている当人にとっては、日々作業する中で何回もカスタマイズして改良を重ねてきたものなので、本当に操作しやすく、毎日快適に作業できています。

人とPCを繋ぐインターフェースは、キーボードやマウスといった入力デバイスですが、これらの追加・変更や設定のカスタマイズによって操作性が向上すると、思考や思想、ツール選定や作業環境が劇的に変わるんだなと実感しています。
キーマップの最適化によりショートカットの発動が快適にできるようになったことで、Macや各ツールのショートカットを調べてよく使うようになりましたし、GUIよりもCLIやTUIを好むようになりました。なるべくマウスなどのポインティングデバイスを使わず、キーボードから手を離さずに作業したいとう気持ちも強くなってきます。

これまでは、外部モニター2枚使って作業していたのですが、アプリを一瞬で切り替えることができるようになると、視線やポインタを大きく移動させることが煩わしくなるので、今はモニター1枚で作業していて、仮想デスクトップさえも使っていません。PC本体の画面はデスクトップを表示したままファイル置き場としてしか使っていないので、外出時にモニターがない環境であっても、最悪PCの画面だけで何とかなりそうだと思っています。

ブラウザに関しても、以前はタブをたくさん開きっぱなしにしていました。しかし[Vimium](https://chromewebstore.google.com/detail/vimium/dbepggeogbaibhgnhhndojpepiihcmeb?hl=ja)やRaycastのGitHub拡張機能との組み合わせによって、タブ、ブックマーク、履歴、Pull Request、Issueを検索して一瞬で開けるようになったので、用が済んだらすぐ閉じるようになり、タブを探してクリックすることがほぼなくなりました。

この境地に至るまでには、Vimの習得やMac・各種ツールのショートカットを覚えることも含めて、とても長い道のりがあったので、安易にはおすすめできませんが、少しでもキーボードに興味を持ってもらい、まずは1つのキーからでも良いので、[Karabiner-Elements](https://karabiner-elements.pqrs.org/)などを使ってキーマップを変更してみようかな、と思ってもらえたら嬉しいです！

少しずつ自分好みにカスタマイズしていければ、操作性が向上し、どんどん快適になっていくはずです。是非あなただけの最強の設定を探してみてください。
